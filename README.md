# AulaFix
AulaFix es una aplicación web para registrar y gestionar incidencias de bibliotecas.

## Instalacion
1. Clona o descarga el repositorio en tu maquina local.
2. Accede al directorio del proyecto y ejecuta el contenido de aulafix.sql en MySql Workbench.
3. Abre XAMPP Control Panel y ejecuta el Apache (en Actions presiona Start).
4. En tu buscador, escribe en la barra de direcciones "localhost".
5. Desde localhost, accede al directorio del proyecto para ejecutarlo.
